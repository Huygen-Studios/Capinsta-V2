# Privacy

Your project editing and local media processing stay in your browser. When you use AI captions, Capinsta sends the required extracted audio directly to Google Gemini using the API key you provide. Translation sends caption text directly to Google.

Capinsta does not receive your Gemini key, source video, extracted audio, captions, or exported video. Projects and media are stored locally using browser storage. Browser storage and remembered API keys are not encrypted and are accessible to code running under the same site origin.

Exports are decoded, composited, encoded, and downloaded locally. Network access is not needed for ordinary editing or export after required application assets/fonts are loaded; Gemini features require Google network access.
